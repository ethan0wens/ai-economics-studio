# Production bundle MIME incident

On 20 November 2026, the main deployment for `ff8ed9ae037fb3c83bda425f039e7acb2f5bb1dd` passed build and Chromium. Wrangler reported 10 changed assets and candidate version `8b581161-b358-4053-b2aa-dee201b3fc3b`. The production exact-byte request passed. A separate security request to `/assets/index-C0cT9zG4.js` failed JavaScript MIME validation after a successful HTTP response. The complete 460-line production job log was inspected on a GitHub runner with Actions read access. It omitted the exact response status, Content-Type, body and CF-Ray at failure. The workflow restored Worker version `7a5d2354-313b-4786-b76e-ad396408f7da`, then verified bytes and the application receipt at `8e945abf3a51d3224823b22f6d4ef953e0aeaac8`. [Failed workflow and rollback](https://github.com/ethan0wens/ai-economics-studio/actions/runs/44750515897/job/136336918443) · [Full job log review](https://github.com/ethan0wens/ai-economics-studio/actions/runs/44756708637/job/136358220810)

A read-only GitHub runner reproduced HTTP 200, `Content-Type: text/html`, `CF-Cache-Status: HIT` and `Cache-Control: public, max-age=31536000, immutable, no-transform` at the failed asset URL after rollback. The HTML digest prefix `000b3a2b6be8a0c7` matched the rollback application shell byte for byte. Both IAD and EWR returned that HTML on the public request variations. The actual JavaScript entry for the rollback release returned `200 text/javascript` at both locations. No response variant carried content encoding. The old local Wrangler routing reproduced the mechanism directly. A request for an absent bundle received the SPA shell and the broad `/assets/*` immutable rule applied to it. With fallback disabled alone, the broad rule still marked a missing bundle's 404 immutable. [Read-only edge observations](https://github.com/ethan0wens/ai-economics-studio/actions/runs/44754994137/job/136352262987)

The confirmed defect was that missing bundle URLs could serve an immutable cache entry for the HTML shell. That explains a failure mode that can survive cache revalidation and differ across requests or deployed versions. The response at the exact failure instant and its Cloudflare point of presence were not retained, so the recorded data does not establish the original request's full propagation history.

The fix serves real static assets and rewrites only direct `/documentation` navigation to the shell. Existing hash navigation still works. Vite emits the new hashed assets under `/bundles/v2/`, outside the old immutable prefix. The build generates exact cache rules for real bundle files and digest-addressed catalogue files. A missing asset receives a 404 without the immutable rule. The deployment guard checks MIME and bytes together for every built JavaScript and CSS file, reports response metadata and bounded HTML hashes, and retains strict verification and guarded rollback. The public verifier also checks a missing asset on the new namespace.
